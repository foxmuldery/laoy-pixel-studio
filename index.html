老 y 像素工坊

把照片拖进来，炼成高对比复古像素 GIF。本页只作说明，创作请进入工坊。

进入工坊

功能

  • 导入拖入或选择 JPG / PNG / WEBP，也可从样片开始。
  • 像素化调节像素粒度、色板、光影运动、反差与抖动。
  • 导出输出 GIF 或像素图，一次可放入多张。

特点

  • 暗房默认低饱和暗调，光会走、影会呼吸。
  • 色板自适应、电影光、黑白、月光、街灯等现成母版。
  • 本地在浏览器里处理，不强制登录。

隐私政策

本政策适用于「老 y 像素工坊」介绍页与工具（含 laoypixel.grok.me）。使用即表示你了解下述说明。

收集的信息

你放入的照片默认在浏览器本地处理，用于生成像素图与 GIF。本介绍页不收集账号或相册。

使用方式

素材只用于完成你发起的转换。不会出售照片或个人信息。

保存与删除

关闭页面后，未主动导出的内容不会作为账号资产保存。导出文件由你自行保管。

第三方

页面托管与字体加载可能经过 GitHub Pages、Google Fonts 等服务。这些服务仅传输打开页面所必需的数据。

联系

隐私相关请求可通过运营账号联系。政策如有更新，将在本页公示。
